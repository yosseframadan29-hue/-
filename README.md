# تطبيق القرآن (MVP)

نسخة أولية بسيطة لتطبيق قرآن باستخدام Flutter، وتشمل:

- قائمة السور
- عرض الآيات
- بحث نصي داخل الآيات
- مشغل تلاوة بسيط لكل سورة
- حفظ آخر موضع قراءة

## المتطلبات

- Flutter SDK
- Dart SDK

## التشغيل

```bash
flutter pub get
flutter run
```

## ملاحظات

- البيانات هنا تجريبية (`assets/quran_sample.json`) لبدء التطوير بسرعة.
- يمكن استبدالها بقاعدة بيانات قرآن كاملة لاحقًا.
